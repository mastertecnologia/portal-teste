Sidebar staff

Esta página usa o mesmo CSS do ficheiro dist/css/pages/pgm-sidebar-premium.css carregado a partir da pasta webroot. Serve para validar espaçamentos, cores teal, grupos colapsáveis, workspace, busca e modo mini-sidebar sem precisar de sessão CakePHP.

Como abrir: com o servidor a servir webroot como raiz (ex.: bin/cake server -p 8765 na raiz do projeto), abra /sidebar-preview.html. Se abrir o ficheiro em file://, o CSS pode falhar conforme o browser; prefira URL HTTP.

Dica: grupos (Cadastros, Gestão de Incidentes, OS, Contratos, Indicadores, Planner, Cofre de Senhas, Comercial, Faturamento, etc.) começam fechados; ao expandir ou ao escolher uma rota ativa, o estado guarda-se em localStorage (pgmSidebarSectionExpanded), igual ao portal. Mini-sidebar expande todos os grupos temporariamente; ao voltar ao menu largo, reaplica-se o estado guardado.
